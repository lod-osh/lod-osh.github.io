Ecosystem Check API

This API returns localized (U.S. only) environmental information including weather, sir and water quality, hazards, and wildlife. This data is retrieved from NWS, Open-Meteo Air Quality, USGS, EPA, NASA FIRMS, and iNaturalist.

This is an independent project that aggregates information from several sources.

Click an endpoint to expand it and see more information.

No key is needed. The ecosystem check calls live NWS, Open-Meteo, USGS, and iNaturalist data. When a call to a source fails, sample data will be returned instead. (switch to Live only to see those failures).
